Projects

Footstep Power Generation using Piezoelectric Sensors

This project harvests renewable energy from human footsteps using piezoelectric sensors that convert mechanical pressure into electrical energy. The generated power is rectified, stored, and used to run small devices. It offers an eco-friendly solution for generating electricity in high-footfall areas like malls and railway stations.

IoT-Enabled Short-Circuit Protection and Predictive Maintenance for EV Charging Stations

This project presents a smart EV charging station safety system using ESP32 and multiple sensors to detect overcurrent, short circuits, and overheating in real time. Faults are isolated within 14 ms using a relay, while sensor data is uploaded to the cloud for monitoring and predictive maintenance. The system achieves 94.7% accuracy, supports solar integration, and enhances the reliability and sustainability of EV charging—earning the Best Paper Presenter award at SSITCON-2025.

AI-Powered Robotic System for Plastic Detection

Designed and developed an AI-powered robotic system that detects and removes plastic carry bags from public waste using computer vision and automation, improving waste segregation efficiency. Developed under the MeitY Digital India RISC-V Grand Challenge through Krutam Yantra LLP.
